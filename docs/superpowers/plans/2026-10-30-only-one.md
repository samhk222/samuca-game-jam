# Only One Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir a cena de exemplo pelo jogo "Only One": memorizar onde está a única vela diferente, clicar nela no escuro, menor tempo vence; tabuleiros reprodutíveis por ID.

**Architecture:** Lógica pura (dificuldade, ID, geração, estado da rodada, recordes) em scripts `RefCounted` sem dependência de nós, testados headless por um runner mínimo. A cena `main.tscn` faz só layout e liga os sinais; `play_area.gd` (um `Control`) desenha velas, escuridão, lanterna e radar via `_draw()` e repassa cliques ao estado da rodada.

**Tech Stack:** Godot 4.7, GDScript, renderer Compatibility, sem addons de runtime.

**Spec:** `docs/superpowers/specs/2026-10-30-only-one-design.md`

## Global Constraints

- Godot 4.7, GDScript, viewport 960×540, stretch `canvas_items`, renderer `gl_compatibility`.
- Export Web (`./scripts/export-web`) deve continuar funcionando.
- Persistência só em `user://` (arquivo simples). Nada de SQLite nem rede.
- Sem assets externos: velas desenhadas por código.
- Scripts de lógica usam `preload("res://...")` em vez de `class_name` (o runner headless `--script` não depende do cache global de classes).
- Texto da UI em português.
- Todo o tuning (tabela de dificuldade, penalidades, durações) vive em `scripts/game/difficulty.gd` e `scripts/game/powerups.gd`.

## Review Focus

1. ID digitado inválido (vazio, minúsculas, espaços, nível fora de 0–3, lixo) → não quebra; mostra "ID inválido" e mantém o tabuleiro atual. Teste em Task 2.
2. Mesmo ID gera tabuleiro idêntico em chamadas repetidas e independe do tamanho da área em pixels (posições normalizadas 0–1). Teste em Task 3.
3. 70 velas (Insano) sempre cabem sem sobreposição; geração nunca entra em loop infinito. Teste em Task 3.
4. Clique/power-up fora da fase escura (antes de acender, durante o aceso, após acertar) é ignorado — não soma penalidade nem consome power-up. Teste em Task 4.
5. Arquivo de recordes ausente ou corrompido → começa vazio sem erro. Teste em Task 5.

### Task 3: Gerador de tabuleiro determinístico

**Files:**
- Create: `scripts/game/board_generator.gd`, `tests/test_board_generator.gd`

**Interfaces:**
- Consumes: `Difficulty.get_level(level)`.
- Produces: `static func generate(seed: int, level: int) -> Dictionary` →
  `{candles: Array[Vector2] (posições normalizadas 0–1, centro da vela), unique_index: int, diff: String, level: int, seed: int}`.
  - `const CANDLE_SIZE_NORM := Vector2(0.035, 0.12)` (fração da área; usado também pelo drawer e hit-test).
  - Algoritmo: `RandomNumberGenerator` com `seed = seed * 4 + level`; posições por amostragem com rejeição (distância mínima entre centros ≥ 1.3× tamanho da vela, margem 0.06 nas bordas, máx. 2000 tentativas por vela); se falhar, cair para grade jitterizada embaralhada pelo mesmo RNG (garante término). `unique_index = rng.randi_range(0, count-1)`; `diff = diffs[rng.randi_range(0, diffs.size()-1)]`.

- [ ] **Step 1:** Testes:
  - `test_deterministic`: `generate(42, 2) == generate(42, 2)` (comparar candles, unique_index, diff)
  - `test_seed_changes_board`: `generate(42,1).candles != generate(43,1).candles`
  - `test_counts_per_level`: `generate(7, l).candles.size() == [8,20,40,70][l]`
  - `test_no_overlap_insane`: para seeds 0..19, nível 3: toda dupla de velas com `abs(dx) >= CANDLE_SIZE_NORM.x` ou `abs(dy) >= CANDLE_SIZE_NORM.y`
  - `test_inside_bounds`: todas as posições em `[0.03, 0.97]` (x) e `[0.08, 0.92]` (y)
  - `test_diff_from_level`: `generate(s, 0).diff == "flame_blue"` para s em 0..9; nível 1 sempre em `["flame_orange","flame_tilted"]`

### Task 4: Estado da rodada

**Files:**
- Create: `scripts/game/round_state.gd`, `tests/test_round_state.gd`

**Interfaces:**
- Consumes: board dict da Task 3, `Difficulty`, `Powerups`.
- Produces: `extends RefCounted`
  - `enum Phase { WAITING, LIT, DARK, DONE }`
  - `func _init(board: Dictionary)`; `var phase: Phase`; `var elapsed: float`; `var penalty: float`; `var misses: int`; `var used: Dictionary` (id → true).
  - `func light_up() -> bool` — só em WAITING → LIT.
  - `func tick(delta: float) -> void` — em LIT conta até `lit_time` e passa para DARK (sobra de delta não conta); em DARK soma em `elapsed`.
  - `func click(norm_pos: Vector2, area_size: Vector2) -> String` → `"hit" | "miss" | "ignored"`. Hit-test: retângulo da vela única (`CANDLE_SIZE_NORM * area_size`, centrado) expandido por `hit_tolerance` px. Miss soma `Difficulty.MISS_PENALTY`. Hit → DONE.
  - `func use_powerup(id: String) -> bool` — só em DARK e se não usado; soma `penalty`.
  - `func total_time() -> float` = `elapsed + penalty`.

- [ ] **Step 1:** Testes (board fixo construído à mão: 2 velas em `(0.2,0.5)` e `(0.8,0.5)`, unique_index 1, level 0; area `Vector2(600, 500)`):
  - `test_flow`: WAITING → `light_up()` true → LIT; `tick(1.0)` ainda LIT; `tick(1.5)` → DARK, `elapsed == 0`
  - `test_timer_only_in_dark`: após DARK, `tick(2.0)` → `elapsed == 2.0`
  - `test_hit`: em DARK `click(Vector2(0.8,0.5), area) == "hit"`, phase DONE
  - `test_miss_penalty`: `click(Vector2(0.2,0.5), area) == "miss"`, `penalty == 1.0`, `misses == 1`
  - `test_tolerance`: nível 0, clique 15 px à direita da borda da vela única → `"hit"`; mesmo clique com level 3 → `"miss"`
  - `test_ignored_outside_dark` (Review Focus 4): clicks em WAITING, LIT e DONE → `"ignored"`, penalty inalterada; `use_powerup("flash")` em WAITING → false e `used` vazio
  - `test_powerup_once`: em DARK `use_powerup("radar")` true, penalty 4.0; segunda vez false, penalty 4.0
  - `test_total`: elapsed 2.0 + 1 miss + flash → `total_time() == 6.0`
